2 Needed now — before the system can go live

Eight items. Without these the web application cannot be deployed for real use, regardless of how much development is completed.

1 Domain name Required

Registered by: IT or Administration · Renewed annually

What it is
The web address staff type to reach the system. For this deployment it is emp.klutchcleaning.com, a subdomain of the existing company domain.
Why this project needs it
Employees need a stable, memorable address. It is also the identity that the security certificate is issued against and that the mobile app will point at.
If we do not have it
Staff would reach the system by a raw numeric server address, which cannot be secured with a normal certificate, is impossible to remember, and changes if the server is ever moved. Not workable for a company-wide rollout.
How to obtain it
If the company already owns a domain, no purchase is needed — IT simply creates a subdomain, which is free and takes minutes. Only if there is no company domain does one need buying, from any registrar.
Cost
Free if using an existing company domain. Otherwise roughly $10–20 per year.
Lead time
Minutes for a subdomain; up to 24 hours for a new domain to become active worldwide.

2 Web hosting or server Required

Purchased by: IT · Monthly or annual

What it is
The computer, in a data centre or in our own server room, that runs the application continuously.
Why this project needs it
The system currently runs only on a developer's machine. It must move to a server that is always on and reachable by every employee.
If we do not have it
There is no product. Development can continue but nobody outside the development machine can use it.
How to obtain it
Three viable routes: (a) shared PHP hosting, cheapest and adequate for a few hundred employees; (b) a small virtual private server, recommended, since it allows scheduled tasks and background jobs the system will eventually need; (c) an internal company server, which keeps all employee data on premises. Requirements to quote against: PHP 8.2+, MySQL, and the extension list in the companion register.
Cost
Shared hosting $3–10/month. Virtual server $10–40/month. Internal server: no new spend.
Lead time
Same day for hosted options. Internal provisioning depends on IT.

3 SSL certificate Required — functional, not optional

Issued by: hosting provider · Auto-renewing

What it is
The credential that produces the padlock in the browser and encrypts traffic between employee and server.
Why this project needs it
Two reasons, and the second is the one people miss. First, employee data and passwords must be encrypted in transit. Second — browsers refuse to provide GPS location over an unencrypted connection.
If we do not have it
Location-based check-in stops working entirely. Not degraded — refused by the browser as a hard security rule we cannot override. Since GPS check-in is the core feature of this product, the system without a certificate does not perform its primary function. Passwords would also travel in readable form.
How to obtain it
Nearly every host now issues free Let's Encrypt certificates with a single click, renewing automatically. Ask the provider to confirm this is included before purchasing hosting.
Cost
Free in almost all cases. Only buy a paid certificate if company policy demands a specific issuer ($50–200/year).
Lead time
Minutes, once the domain points at the server.

4 Email sending service Required

Configured by: IT with development team

What it is
A service permitted to send automated email on behalf of our domain — password resets, leave notifications, scheduled reports.
Why this project needs it
Any feature that contacts an employee outside the application depends on it. Password reset is the critical one: without email, a locked-out employee can only be helped manually by an administrator.
If we do not have it
This is not a hypothetical — it is the current state. The system is configured to write emails into a log file instead of sending them. Not one message has ever reached a recipient. Features already built and paid for are sitting inert behind a single configuration setting. This is the fastest available win on the whole list.
How to obtain it
If the company uses Google Workspace or Microsoft 365, this is already owned — IT supplies existing credentials and the work is configuration only, no purchase. Otherwise use a dedicated sender such as Brevo, Mailgun or Amazon SES. Whichever is chosen, IT must add sender-authentication records to the domain, or messages will be filed as spam.
Cost
Free if using existing Workspace or 365. Dedicated services offer free tiers around 300 emails/day; paid plans start near $15–25/month — well above what this system needs.
Lead time
Under an hour with existing credentials. One to two days for a new service, allowing for domain verification.

5 Backup storage Required

Owned by: IT · Monthly

What it is
Somewhere separate from the server to keep automatic copies of the database.
Why this project needs it
Attendance records are the evidence base for payroll and for any employment dispute. They cannot be reconstructed if lost — nobody can remember what time two hundred people arrived last March.
If we do not have it
A disk failure, a mistaken deletion or a ransomware incident destroys the complete attendance history permanently. This is the highest-consequence, lowest-cost item on the entire list. It is also worth noting that a backup stored on the same server is not a backup; it fails with the server.
How to obtain it
Many hosting plans include automated backups — confirm this when purchasing, as it may make separate storage unnecessary. Otherwise any object storage service, or a scheduled copy to internal company storage.
Cost
Often included with hosting. Standalone storage is roughly $1–5/month at this data volume.
Lead time
Same day.

6 Company branding assets Needed

Supplied by: Marketing or Management · One-off

What it is
The official company logo in high resolution, the approved colour codes, and a preferred typeface if one is mandated.
Why this project needs it
The logo appears on the login screen, in the sidebar, and on every exported PDF report — documents that may be shown to auditors or attached to employment matters.
If we do not have it
Nothing breaks. A neutral placeholder logo is in place and the system is fully functional. The consequence is presentational: exported reports look unofficial. Worth resolving before any demonstration to senior management, because it is the first thing noticed and creates a poor impression of otherwise finished work.
How to obtain it
Request from Marketing. Useful formats: SVG or PNG with transparent background, a square version for small spaces, and the brand colour codes.
Cost
None if assets exist. Only relevant if a designer must produce them.
Lead time
Depends entirely on internal response.

7 Privacy policy and employee notice Required

Approved by: HR and Legal · One-off, reviewed periodically

What it is
A written statement, shown to employees, explaining what the system records about them, why, how long it is kept and who can see it.
Why this project needs it
This system records physical location at check-in and check-out. Under GDPR and equivalent laws worldwide, location is sensitive personal data. Employees must be informed before collection begins, not afterwards.
If we do not have it
The organisation carries real legal exposure and, just as importantly, a staff-relations problem. Location tracking introduced without explanation is reliably perceived as surveillance, and that perception is very hard to reverse once formed. A clear notice stating that location is recorded only at the moment of check-in and check-out, and never between resolves most objections before they arise — it is the single most useful sentence in the document.
How to obtain it
HR drafts it; Legal reviews. The development team supplies the factual list of what is stored, which is short and precise: name, employee code, department, check-in and check-out times, coordinates at those two moments, and the network address used.
Cost
None if handled internally.
Lead time
One to two weeks including legal review. Start early — it runs in parallel with development and blocks rollout, not build.

8 Commercial interface template licence Confirm before delivery

Confirmed by: whoever purchased it · One-off

What it is
The administrative interface is built on SmartHR, a professionally designed Bootstrap template bought from a template marketplace. It is the only purchased software component in the project.
Why this project needs it
It provides the complete visual design — layout, navigation, forms, tables, charts. Recreating equivalent design work from scratch would add several weeks and a designer to the budget.
If we do not have it
Using a marketplace template without a valid licence is a copyright breach, and it surfaces at the worst possible time: during client delivery or an audit, when the work is already complete. Two questions need answering. (a) Is a valid purchase receipt and licence key on file, held by the company rather than an individual developer? (b) Is it the correct tier — marketplace templates are typically sold under a "regular" licence for one product whose end users are not charged, and an "extended" licence where they are. If this system is ever sold or offered as a paid service to another organisation, the extended licence applies.
How to obtain it
Locate the original purchase record. If it cannot be found, or was bought under a personal account, re-purchase under the company account — the cost is trivial next to the risk.
Cost
Typically $25–60 regular, or $300–900 extended, one-off.
Lead time
Immediate. This is an administrative check, not a technical task.
Item 8 was identified during the dependency audit and was not in earlier versions of this list. It is included because it is the only item on the entire list carrying a legal rather than a technical risk, and because it costs almost nothing to resolve now.

3 Before the mobile app can be published

Six items, needed only when the mobile application phase is approved. Two have long lead times and can be started well in advance of any development.

9 Google Play Console account Required for Android

Registered by: company, under a company Google account · One-off fee

What it is
The developer account required to publish an Android app on the Google Play Store.
Why this project needs it
There is no other practical way to distribute an Android app to staff and keep it updated automatically.
If we do not have it
The app can only be distributed as an installer file sent to employees, who must then permit installation from unknown sources — a poor experience, a security-policy problem on managed devices, and no automatic updates.
How to obtain it
Register at the Play Console with a company Google account. Organisation registration requires company details and, since 2023, identity verification. The same Google account also covers Firebase and Google Maps (items 11 and 15) — so choosing which company address owns it is a decision worth making once, carefully.
Cost
$25 one-time, for the lifetime of the account.
Lead time
1–3 days including verification.

10 Apple Developer Program Longest lead time in the project

Registered by: company · Annual renewal

What it is
The paid membership required to publish an iOS app on the App Store.
Why this project needs it
Any employee using an iPhone needs the app from the App Store. Apple permits no alternative route for normal distribution.
If we do not have it
No iPhone users can be supported at all. Depending on the workforce this could exclude a large share of staff. There is no workaround comparable to the Android installer route.
How to obtain it
Enrol as an organisation, not an individual — organisation enrolment requires a D-U-N-S number, a company identifier issued by Dun & Bradstreet. If the company does not already have one, it must be requested first, and that alone can take a week or more. Register the account under a company Apple ID, never a personal one — recovering an App Store account from a departed employee is extremely difficult.
Cost
$99 per year, recurring. If the membership lapses, the app is removed from the store.
Lead time
1–2 weeks, occasionally longer. This is the longest lead time on the list and it is entirely independent of development. If an iOS app is likely at any point, begin enrolment now — the cost of starting early is $99; the cost of starting late is a two-week delay to launch.

11 Firebase project (push notifications) Needed for mobile

Created by: development team, under the company Google account

What it is
Google's free messaging service, the standard route for delivering push notifications to both Android and iPhone.
Why this project needs it
Notifications are what make a mobile app useful rather than merely available: check-in reminders, leave approvals, shift changes.
If we do not have it
The app still works fully, but only tells employees anything when they open it. Most of the practical benefit of having an app rather than a website is lost.
How to obtain it
Created free in the Firebase console using the same company Google account as item 9. Apple push additionally requires a key generated from the Apple Developer account in item 10.
Cost
Free. Cloud Messaging has no charge at any volume this project will reach.
Lead time
Under an hour, once the Google account exists.

12 File and photo storage Recommended

Purchased by: IT · Monthly

What it is
Dedicated storage for employee photographs, documents and any check-in photos, held separately from the application server.
Why this project needs it
Image files grow steadily and are best kept off the main server so they can be backed up and served independently.
If we do not have it
Files are stored on the application server itself, which works perfectly well at small scale. The consequences arrive later: the server disk fills, backups become large and slow, and moving to a bigger server becomes harder. Not urgent, but easier to arrange at the start than to retrofit.
How to obtain it
Any object storage service — Amazon S3, Backblaze B2, Cloudflare R2, or equivalent. The application supports this through configuration; no rework is needed.
Cost
Roughly $1–5/month at expected volumes.
Lead time
Same day.

13 App store listing assets Required to publish

Produced by: Marketing with development team · One-off

What it is
The material both stores demand before they will accept an app: an icon, screenshots at several device sizes, a short and long description, a category, a support email address and a link to the privacy policy.
Why this project needs it
Neither store will publish without them. They are submission requirements, not marketing extras.
If we do not have it
Submission is rejected. This regularly delays launches by a week or two because it is treated as an afterthought — the app is finished, and then someone has to write descriptions and produce screenshots at exact pixel dimensions. Prepare it during development, not after.
How to obtain it
Screenshots are produced by the development team from the finished app; text and icon by Marketing using the branding from item 6. Note that the privacy policy from item 7 is a mandatory field — the two items are linked.
Cost
None if produced internally.
Lead time
2–3 days, and can be prepared in advance.

14 App signing keys Irreplaceable if lost

Generated by: development team · Held by: company, permanently

What it is
Cryptographic keys that prove each app update genuinely comes from us. Every release must be signed with the same key as the original.
Why this project needs it
Both stores reject any update not signed with the original key.
If we do not have it
Losing the Android signing key means the app can never be updated again. Not delayed — never. The only remedy is publishing an entirely new app under a new listing and asking every employee to uninstall the old one and install the replacement, losing all installs and reviews. This is a genuinely unrecoverable failure and it has ended app products.
How to obtain it
Generated free by the development team at first release. The essential part is custody: store the key and its password in the company password manager, held by IT rather than by an individual developer, with a second copy in a separate secure location. Google offers Play App Signing, where Google retains a backup — this is strongly recommended and should be enabled at first upload.
Cost
None.
Lead time
Immediate. The custody arrangement is the part requiring a decision.

4 Only if the corresponding feature is approved

Eight items. None are needed for the system to work. Each is listed with the ongoing commitment it creates, so the cost of a feature decision is visible before it is taken. Several can be declined with no consequence at all.

15 Google Maps Platform Optional

What it is
A billed Google service for drawing interactive maps inside our own pages.
Why this project needs it
Only to show check-in locations as pins on a map embedded in the dashboard, rather than as a link.
If we do not have it
Nothing is lost operationally. Location is still recorded, stored, exported to PDF and Excel, and remains fully usable. Each record already carries a link that opens the exact position in Google Maps in a new tab, which costs nothing and requires no account. The embedded map is a presentation upgrade only. There is also a free alternative — OpenStreetMap with the Leaflet library — which requires no account and no billing, and is the sensible first choice.
How to obtain it
Requires a Google Cloud project with a credit card on file, even to use the free monthly allowance.
Cost
Free monthly allowance covers light use; beyond it, usage-based. Budget $0–200/month. Set a spending cap on day one.
Lead time
Under an hour.

16 Face recognition service Only if approved

What it is
A cloud service (AWS Rekognition, Azure Face) that confirms a check-in photo matches the employee on record.
Why this project needs it
To prevent one employee checking in on behalf of another.
If we do not have it
A simpler approach solves most of the problem at no cost. Capture a photograph at check-in and store it against the record for HR to review. This deters buddy-punching almost as effectively, because employees know a photo exists, and it needs no external service, no recurring fee and no biometric consent process. Automatic matching is a refinement, not a prerequisite — and it is our recommendation to start with photo capture and review the need for matching later.
How to obtain it
Cloud provider account with billing. Legal review is mandatory first — see item 22.
Cost
Roughly $1 per 1,000 comparisons. For 200 employees checking in twice daily, approximately $12/month. Modest financially; the compliance burden is the real cost.
Lead time
Hours technically. Weeks once legal and consent processes are included.

17 AI provider account Optional

What it is
An API account with an AI provider such as Anthropic or OpenAI.
Why this project needs it
Only for proposed intelligent features — plain-language report queries, absence-pattern detection, automatic summaries for managers.
If we do not have it
No effect whatsoever on any current or planned core function. These are enhancements to an already-complete reporting capability.
How to obtain it
Register and add a payment method. Confirm first whether employee data may be sent to an external provider under company policy — often it may not, which settles the question before cost enters into it.
Cost
Usage-based, typically $20–100/month at this scale. Set a hard spending cap.
Lead time
Under an hour.

18 Fingerprint terminals and vendor SDK Only if approved

What it is
Physical biometric devices mounted at entrances, plus the manufacturer's software kit to read from them.
Why this project needs it
Only if the organisation wants fixed-point biometric attendance in addition to phone-based check-in.
If we do not have it
Nothing is lost — phone-based check-in with GPS already covers attendance, and covers field and remote staff that fixed terminals cannot. Terminals suit factory or single-site environments where staff do not carry phones.
How to obtain it
Purchase hardware; obtain the SDK from the manufacturer. Two warnings. First, this creates genuine vendor lock-in: each manufacturer's integration is different, and switching brands means rebuilding the integration. Second, devices sit on the internal network and must reach our server, which needs IT network configuration — frequently the hardest part of such projects, and consistently underestimated.
Cost
$100–500 per device, plus integration effort per manufacturer.
Lead time
2–6 weeks including procurement, delivery and network configuration.

19 SMS or WhatsApp messaging Only if approved

What it is
A service such as Twilio for SMS, or an approved Business Solution Provider for WhatsApp.
Why this project needs it
To reach employees who do not use email regularly — common among field, factory and shift staff.
If we do not have it
Email (item 4) and push notifications (item 11) cover most needs. SMS matters mainly where staff have no company email address, which is worth checking against the actual workforce before committing.
How to obtain it
SMS is straightforward: register, add billing, begin. WhatsApp is not. It requires a verified Meta Business account, an approved provider, and message templates individually submitted for approval — a process of weeks with a real chance of rejection. Do not plan a launch date around WhatsApp availability.
Cost
SMS roughly $0.01–0.10 per message, varying sharply by country. WhatsApp is priced per conversation. At scale this becomes the largest recurring cost on the list — 200 employees × 2 messages daily is approximately $120/month at mid-range rates.
Lead time
SMS: 1–2 days. WhatsApp: 2–6 weeks.

20 Single sign-on consent Optional

What it is
Permission and configuration allowing staff to sign in with their existing Microsoft 365 or Google Workspace account instead of a separate password.
Why this project needs it
Removes one more password to forget, and means access ends automatically when someone leaves the company — a genuine security benefit.
If we do not have it
The system's own login works fully. The cost is administrative: HR must create and later disable accounts manually, and there is a risk of a departed employee's access lingering. Grows more valuable as headcount rises.
How to obtain it
No purchase — the company already owns the directory. It needs an IT administrator to register the application and grant consent. The blocker is usually approval time, not cost.
Cost
None beyond existing licences.
Lead time
Hours of technical work, once IT approval is granted.

21 Payroll or tax advisor Only if payroll is approved

What it is
A qualified accountant or payroll specialist for the country of operation.
Why this project needs it
Payroll calculation depends on tax bands, statutory deductions, overtime law and contribution rules that differ by country and change annually.
If we do not have it
Payroll must not be built. The development team can build the calculation engine but cannot supply the rules, and cannot verify the output is lawful. Incorrect payroll creates liability far exceeding the value of the feature. The strongly recommended alternative is to export verified attendance and approved overtime into whatever payroll system the company already uses — this delivers most of the benefit, carries none of the risk, and is a fraction of the effort.
How to obtain it
Engage the company's existing accountant, who already knows the rules that apply.
Cost
Professional fees, plus an annual review as rates change. The recurring commitment is easy to overlook.
Lead time
Weeks, and continuing.

22 Legal and compliance review Mandatory for biometrics

What it is
Formal legal advice on collecting employee location and, if approved, biometric data.
Why this project needs it
Face and fingerprint data are treated as special category personal data almost everywhere, with stricter rules than ordinary employee records — explicit consent, defined retention periods, and in some jurisdictions statutory damages per individual for breaches.
If we do not have it
For location alone, the privacy notice in item 7 is generally sufficient. For biometrics it is not. Several jurisdictions allow employees to claim substantial per-person damages for non-compliant biometric collection, without needing to show any harm. For a two-hundred-person workforce that is a material corporate exposure, and it is created by a feature the system does not need.
How to obtain it
Company legal counsel or an employment-law specialist. Commission this before committing to items 16 or 18, not after building them.
Cost
Professional fees.
Lead time
2–4 weeks. Should gate the decision, not follow it.
